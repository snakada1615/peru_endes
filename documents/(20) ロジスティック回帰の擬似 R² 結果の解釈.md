#### **栄養・疫学研究における妥当性**

-   **栄養失調**のような複雑な健康アウトカムでは、**R² = 0.06–0.10** は**現実的で妥当**な範囲
-   多要因（遺伝、環境、社会経済など）が関与するため、調査可能な変数だけで高い説明力を期待するのは困難
-   **DHS データ**を用いた類似研究では、この程度の擬似 R² が一般的

#### **比較的良好な指標**

-   **Cox-Snell = 0.0633** は「説明変数が何もない状態」と比較して **約6.3%の改善**
-   **Nagelkerke = 0.104** は「調整済み改善度」として **約10.4%の説明力**

library(pROC)

# 分類精度
threshold <- 0.5
predicted_class <- ifelse(predicted_prob > threshold, 1, 0)
accuracy <- mean(predicted_class == model.response(model.frame(model_logit)))
