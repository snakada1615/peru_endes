# Rでデータフレームをマージ・結合する際のラベル抽出における注意点

---

## 1. ラベル情報の構造理解
- **変数ラベル**・**値ラベル**は`attributes()`で付与されていることが多い（SPSS・Stata等由来のデータは特に）。
- 変数ごとに`var_label()`、値ラベルは`attr(x, "labels")`や`sjlabelled::get_labels()`で抽出する。

---

## 2. マージ・結合処理での落とし穴
- `dplyr::left_join()` や `merge()` などでマージした場合、**ラベル情報は保持されない場合がある**。
    - 結合後は、ラベル属性が消失することがあるため、必要な場合は再付与が必須。

---

## 3. ラベル抽出と管理のポイント
- データフレームをマージする前に、**どの変数のラベル情報が必要かを明確化**しておく。
- 結合元の変数名・ラベル・値ラベルを**事前に一覧化**して保存しておくと便利。
    - 例：変数名、変数ラベル、値（カテゴリ値）、値ラベルのデータフレームを作成し保存
- 結合後、labelledクラスの場合は`set_label()`や`sjlabelled::copy_labels()`でラベルを再コピーできる。

---

## 4. 抽出時のテクニック
- **labelledクラスの変数は、単なる数値や文字ではなく「ラベル付きベクトル」として扱う必要がある**。
- `val_labels()`や`get_labels()`は、実データそのものではなく、ラベル定義を返す関数を選ぶ。
- ラベル抽出時は、必ず`names()`や`attributes()`を使ってラベルの名前部分（"Home"など）を明示的に取得する。

---

## 5. マージ後のラベル情報点検
- 結合後のデータフレームで、**属性が残っているか**、`str()`や`attributes()`で必ず確認する。
- 必要なら`dplyr::mutate()`や`sjlabelled::set_label()`で改めてラベルを付与する。

---

## 6. その他の注意点
- 特に大量のカテゴリ変数をマージする場合、「ラベル定義表」を別途作っておくと品質管理に役立つ。
- 長いワークフローの中では、**ラベル失念による分析誤り**が発生しやすいので要注意。

---

## 例
```r

labels <- purrr::map_dfr(names(df), function(v) {
  lab <- var_label(df[[v]])
  vals <- attr(df[[v]], "labels")
  if (is.null(vals)) {
    tibble(varname = v, varlabel = lab, val = NA_integer_, vallabel = NA_character_)
  } else {
    tibble(
      varname = rep(v, length(vals)),
      varlabel = rep(lab, length(vals)),
      val = as.vector(vals),
      vallabel = names(vals)
    )
  }
})
print(labels)

```

---

**まとめ：**  
データフレームのマージ前後でラベル情報が消えるリスクを必ず認識し、抽出・管理・再付与の作業を明示的に行うのがポイントです。
