# LASSOを大量変数で使う際の基本的な考え方

```         
モデルに導入前から明らかに相関を持っていることがわかる変数群（例えば４種の値を取るカテゴリ変数から作成した4つのダミー変数全て）を組み込むことは問題でしょうか？
```

**結論（要点）**

-   LASSOは多くの候補変数から重要な説明変数を自動選択できる手法だが、前処理としての変数の整理や適切なダミー符号化は依然として重要である。
-   完全に相関するダミー変数（例えば4分類の全4ダミー）をそのまま投入するとモデルの学習が不安定になるため、通常は1つ落とした「参照カテゴリ」を設けることで多重共線性を回避する。
-   ただし、LASSO自体は相関する説明変数のうちいずれかを選ぶ性質があるため、前処理段階で「唯一の正則化項が効くように」適切な符号化を行えば、過度な事前絞り込みは不要となる。

------------------------------------------------------------------------

## 1. 大量変数にLASSOを使う際の留意点

1.  **標準化（スケーリング）の徹底**
    -   L1正則化ペナルティは変数のスケールに敏感のため、必ず平均0・分散1に標準化してから適用する。
    -   `glmnet`などRの実装では `standardize=TRUE` オプションを使うのが一般的。
2.  **ペナルティパラメータ λ の選択**
    -   λは交差検証（CV）で決定し、過学習防止と変数選択のバランスを取る。
    -   λの系列を細かく設定し、`cv.glmnet` 等で最適点（最小MSEまたは1SEルール）を選ぶ。
3.  **相関変数への挙動**
    -   高い相関を持つ変数群では、LASSOはその中の一部のみを選択する傾向がある（変数を「まとめて」抑制するわけではない）。
    -   強い相関がある場合、選択結果がデータの細かい揺らぎに左右されやすいため、安定性を調べる（ブートストラップや安定的選択法）ことが望ましい。
4.  **変数の事前絞り込みの是非**
    -   LASSOは多数の変数から選択する力があるため、初めから数百変数をほぼそのまま投入しても構わない。
    -   ただし、**多重共線性**や**過度に重複する情報**を含むと、選択の解釈や安定性に問題が生じる。
    -   重要度の低い変数群（ほぼゼロ寄与と予想されるもの）は事前に除外してもよいが、LASSO自体で除外されるため、あえて全量投入してペナルティに任せる運用も一般的。

------------------------------------------------------------------------

## 2. カテゴリカル変数のダミー符号化と多重共線性

### 2.1 参照レベルありのダミー符号化

-   4水準のカテゴリを「4つの0/1ダミー」で完全に表現すると、切片項（intercept）との完全共線性（ダミー・トラップ）が起きる。
-   回避策としては、
    -   1つのレベルを参照カテゴリとして落とし、ダミーは「3個」にする
    -   または、**切片項を外したモデル**にする（ただし一般的でない）

### 2.2 LASSOと完璧な共線性

-   LASSOの数学的最適化問題は「完全共線性があると一意解が得られない」ことがあるため、**完璧に相関する列を含まない形**にするのが無難。
-   部分的に相関するダミー群（例：one-vs-allではなく複数カテゴリ）でも、LASSOが一部を自動で押さえ込むが、事前に参照レベルを落としておくことで解釈性が向上する。

------------------------------------------------------------------------

## 3. 実践的ワークフローの例

1.  データ読み込み・前処理
    -   欠損値処理、外れ値処理
    -   カテゴリ変数のダミー化（参照レベルを落とす）
    -   数値変数の標準化
2.  λ系列の構築
    -   `glmnet`のデフォルト系列を利用するか、独自に広めの系列を用意
3.  交差検証による最適λの決定
    -   `cv.glmnet(x, y, alpha=1)`
    -   最小MSEのλと1SEルールのλを比較し、安定度と解釈性で選択
4.  選択結果の確認
    -   非ゼロ係数のみを抽出し、どの変数が寄与しているかを見る
    -   ブートストラップやサブサンプリングで選択の安定性を検証
5.  モデルチューニング・再評価
    -   必要に応じて相互作用項や多項式項を追加
    -   再度LASSOで自動選択＋CVを行う

------------------------------------------------------------------------

## 4. まとめ

-   **大量変数のままLASSOに投入**しても構わないが、**完全共線性（ダミー・トラップ）は事前に解消**すること。
-   標準化と交差検証によるλ選択は必須。
-   モデル選択後に選ばれた変数の安定性を検証し、実務上の解釈に耐えうる結果になっているかを確認する。
-   カテゴリカル変数は「参照レベルを落とす」伝統的な符号化をした上でLASSOを適用するのがもっとも無難であり、解釈性・数値的安定性ともに向上する。

# 追加質問：州グループIDと単独州IDの混在について

# \*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*

```         
よくわかりました。
ひとつ悩んでいるのは、「州」の扱いです。想定している検証では、対象州によって政府の介入の状況が異なるため地域による差を確認することは重要です。このため介入を受けた州をグルーピングしてearly_treated, late_treated, controlという変数を導入しています。
一方で、地域の自然条件、社会経済条件も重要な要因であり、個別の州を対象とした固定効果という要素も重要ではないかという気もします。この場合に、「州グループID」と「単独の州ID」がモデルの中に混在することで問題が出てくる気もしますが、いかがでしょう？
```

**結論（要点）** 州グループ変数（early_treated, late_treated, control）と個別州ダミー変数を同時にLASSOモデルに投入することは**数学的に完全な多重共線性**を引き起こすため、モデルの推定が不可能になるか非常に不安定になる。これは重大な問題である。一方で、差分差分（DiD）設定においてLASSOを適用する場合は、適切な変数設計により有効な分析が可能である。

------------------------------------------------------------------------

## 1. 問題の核心：完全多重共線性

### 1.1 数学的問題

州グループ変数（`early_treated`, `late_treated`, `control`）は個別州変数の**線形結合**として表現できるため、両者を同時にモデルに含めると完全共線性が発生する。[^(12-lassoを大量変数で使う際の基本的な考え方-1], [^(12-lassoを大量変数で使う際の基本的な考え方-2]

[^(12-lassoを大量変数で使う際の基本的な考え方-1]: <https://www.aeaweb.org/articles?id=10.1257%2Faer.20181169>

[^(12-lassoを大量変数で使う際の基本的な考え方-2]: <https://www.nber.org/system/files/working_papers/w25904/w25904.pdf>

例：

-   もし州A、B、Cが`early_treated`に属し、州D、E、Fが`late_treated`に属する場合
-   `early_treated = state_A + state_B + state_C`
-   `late_treated = state_D + state_E + state_F`

この状況では、設計行列が特異行列（singular matrix）となり、正則化なしでは逆行列が計算できないため、通常の回帰分析は実行不可能である。

### 1.2 LASSOでの挙動

LASSOは完全共線性に対しても一定の頑健性を持つが、以下の問題が発生する：[^(12-lassoを大量変数で使う際の基本的な考え方-3], [^(12-lassoを大量変数で使う際の基本的な考え方-4]

[^(12-lassoを大量変数で使う際の基本的な考え方-3]: <https://pmc.ncbi.nlm.nih.gov/articles/PMC4941428/>

[^(12-lassoを大量変数で使う際の基本的な考え方-4]: <https://www.pnas.org/doi/pdf/10.1073/pnas.1510506113>

-   完全に相関する変数群の中から**任意に一部を選択**する（選択が不安定）
-   係数の推定値が **データの微細な変動に過度に敏感**になる
-   モデルの解釈が困難になる（同じ情報を表す複数の変数が異なる係数を持つ）

## 2. 差分差分設定でのLASSO適用における考慮点

### 2.1 Staggered DiDの課題

近年の計量経済学研究では、**異時点介入（staggered treatment）**を伴う差分差分設定において、従来の二方向固定効果（TWFE）推定量が**負の重み**を持つ可能性があることが判明している。[^(12-lassoを大量変数で使う際の基本的な考え方-5], [^(12-lassoを大量変数で使う際の基本的な考え方-6]

[^(12-lassoを大量変数で使う際の基本的な考え方-5]: <https://www.nber.org/system/files/working_papers/w25904/w25904.pdf>

[^(12-lassoを大量変数で使う際の基本的な考え方-6]: <https://www.jonathandroth.com/assets/files/DiD_Review_Paper.pdf>

この問題は以下の状況で発生する：[^(12-lassoを大量変数で使う際の基本的な考え方-7], [^(12-lassoを大量変数で使う際の基本的な考え方-8]

[^(12-lassoを大量変数で使う際の基本的な考え方-7]: <https://pmc.ncbi.nlm.nih.gov/articles/PMC10771800/>

[^(12-lassoを大量変数で使う際の基本的な考え方-8]: <https://www.tse-fr.eu/sites/default/files/TSE/documents/doc/wp/2022/wp_tse_1362.pdf>

-   早期介入グループが後期介入グループの対照群として使用される
-   介入効果が時間や州によって異質性を持つ
-   結果として、真の介入効果がすべて正でも推定値が負になる可能性がある

### 2.2 LASSO with Treatment Effects

治療効果推定におけるLASSOの適用では、以下のアプローチが推奨される：[^(12-lassoを大量変数で使う際の基本的な考え方-9], [^(12-lassoを大量変数で使う際の基本的な考え方-10]

[^(12-lassoを大量変数で使う際の基本的な考え方-9]: <https://www.stata.com/manuals/causaltelasso.pdf>

[^(12-lassoを大量変数で使う際の基本的な考え方-10]: <https://pmc.ncbi.nlm.nih.gov/articles/PMC4941428/>

1.  **Doubly Robust AIPW（Augmented Inverse Probability Weighting）**：
    -   アウトカムモデルと治療モデルの両方でLASSO選択を実行
    -   どちらかのモデルが正しく特定されていれば一貫性を保持
2.  **Treatment-specific LASSO**：
    -   各治療グループ（early_treated, late_treated, control）に対して個別にLASSOを適用
    -   グループ間の異質性を適切に捕捉

## 3. 実践的解決策

### 3.1 推奨アプローチ1：階層的モデリング

``` r
# 段階的アプローチ
# ステップ1：グループレベルの効果を推定
model_group <- cv.glmnet(X_group, y, alpha=1)

# ステップ2：グループ効果を制御した上で州固有効果を推定
y_residual <- y - predict(model_group, X_group)
model_state <- cv.glmnet(X_state, y_residual, alpha=1)
```

### 3.2 推奨アプローチ2：事前に問題を回避

-   **州グループ変数のみ**を使用し、個別州ダミーは除外
-   または **個別州ダミーのみ**を使用し、グループ変数を除外
-   分析目的に応じていずれかを選択

### 3.3 推奨アプローチ3：制約付きLASSO

**Group LASSO**を使用して、関連する変数群を一括で選択・除外する：[^(12-lassoを大量変数で使う際の基本的な考え方-11]

[^(12-lassoを大量変数で使う際の基本的な考え方-11]: <https://arxiv.org/pdf/2302.03832.pdf>

-   同一州に属する変数を一つのグループとして扱う
-   グループ単位でのペナルティにより、解釈しやすい結果を得る

# 次のステップ：州グループのみでのLASSO分析

以下の手順で、**early_treated, late_treated, control** の3値変数のみを説明変数に含めたLASSO回帰を実行しましょう。

## 1. データ準備

1.  ダミー変数作成

``` r
# 例：state_group に "early","late","control" の3水準を持つ場合
df$early_treated <- ifelse(df$state_group == "early", 1, 0)
df$late_treated  <- ifelse(df$state_group == "late", 1, 0)
# control は切片で表現するのでダミー不要
```

2.  目的変数と説明変数行列の定義

``` r
library(glmnet)
y <- df$outcome
X <- as.matrix(df[, c("early_treated", "late_treated")])
```

3.  標準化オプションの設定 `glmnet` はデフォルトで標準化を行うので、特に指定不要です。

------------------------------------------------------------------------

## 2. 交差検証によるλの選択とモデル推定

``` r
set.seed(123)
cv_fit <- cv.glmnet(
  x     = X,
  y     = y,
  alpha = 1,        # LASSO
  nfolds = 10,      # 10分割CV
  type.measure = "mse"
)

# 最適λ
lambda_min <- cv_fit$lambda.min
lambda_1se <- cv_fit$lambda.1se
```
