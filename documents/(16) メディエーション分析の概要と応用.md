# メディエーション分析の概要と応用

**メディエーション分析**とは、介入（独立変数）が結果（従属変数）に与える総効果を、「媒介変数（メディエーター）」を通じた間接効果と、直接効果に分解して推定する手法です。これにより、政策介入がどのようなメカニズム（経路）を通じて最終アウトカムに影響を及ぼすのかを定量的に検証できます。

------------------------------------------------------------------------

## 1. 基本的な概念

1.  **総効果（Total Effect）**
    -   介入 $X$ が結果 $Y$ に与える全体の影響量。
2.  **間接効果（Indirect Effect）**
    -   介入 $X$ → 媒介変数 $M$ → 結果 $Y$ という経路を通じた影響。
    -   $X$ が $M$ に与える効果 $a$ と、$M$ が $Y$ に与える効果 $b$ の積 $a\times b$ として表現。
3.  **直接効果（Direct Effect）**
    -   媒介変数を経由せず、介入 $X$ が直接 $Y$ に与える影響。

これらを数式で表すと以下のようになります。

$$
\begin{aligned}
M &= \alpha + aX + \mathbf{C}\boldsymbol{\gamma} + \varepsilon_M,\\
Y &= \beta + c'X + bM + \mathbf{C}\boldsymbol{\delta} + \varepsilon_Y,
\end{aligned}
$$

-   $a$：$X\to M$ の効果
-   $b$：$M\to Y$ の効果（$X$ を制御後）
-   $c'$：直接効果（$X\to Y$）
-   $\mathbf{C}$：共変量（制御変数）
-   間接効果 = $a \times b$
-   総効果 = $c' + a \times b$

------------------------------------------------------------------------

## 2. メディエーション分析の実行ステップ

1.  **媒介変数の特定**
    -   LASSOで抽出したコア予測因子（例：貧困層プログラム利用、母子保健サービス利用など）を候補とする。
2.  **モデルの推定**
    -   媒介モデル：$M$ を従属変数、$X$（介入）を独立変数として回帰
    -   結果モデル：$Y$ を従属変数、$X$ と $M$ の両方を独立変数として回帰
3.  **効果の分解と検定**
    -   間接効果 $a\times b$ の有意性をブートストラップなどで検定
    -   直接効果 $c'$ の大きさと有意性の確認
4.  **解釈**
    -   間接効果が統計的に有意であれば、「介入が媒介変数を介して結果に影響を与える経路」が実証される。
    -   直接効果が大きい場合は、媒介変数以外の経路も重要であることを示す。

------------------------------------------------------------------------

## 3. Peru栄養政策評価への応用例

-   **介入** $X$：貧困層向け栄養支援プログラムの実施
-   **媒介変数** $M$：母子保健サービス利用率、栄養教育受講率など
-   **結果** $Y$：子どものstunting（二値 or HAZスコア）

手順例：

``` r
# (1) Mモデル
model_M <- glm(M ~ X + covariates, data = data, family = binomial)

# (2) Yモデル
model_Y <- glm(Y ~ X + M + covariates, data = data, family = binomial)

# (3) メディエーション分析
library(mediation)
med_out <-mediate(
  model_M, model_Y,
  treat = "X", mediator = "M",
  boot = TRUE, sims = 1000
)
summary(med_out)
```

-   出力には**ACME（平均間接効果）**、**ADE（平均直接効果）**、**総効果**が含まれます。
-   これにより、「栄養プログラム→保健サービス利用→stunting改善」という経路の強さを定量化し、政策提言の根拠とできます。

------------------------------------------------------------------------

## 4. メリットと留意点

-   **メリット**
    -   政策介入のメカニズムを具体的に明示
    -   効果要因の優先順位付けが可能
    -   メディエーターによる部分的な効果を把握し、プログラム設計にフィードバック
-   **留意点**
    -   共変量の適切な制御が不可欠
    -   因果推論の要件（順序性、無交絡性、モデルの正当化）を満たす設計が必要
    -   ブートストラップによる間接効果の推定誤差評価が推奨される

------------------------------------------------------------------------

## 5. まとめ

メディエーション分析を通じて、**政策介入がどの要因を介してstuntingに影響を与えているか**を明確化し、Peruにおける栄養政策の効果メカニズムを科学的に解明できます。

# 直接効果と間接効果の切り分けの原理

メディエーション分析では、介入（独立変数）から結果（従属変数）への影響を「媒介変数」を介する経路と、媒介変数を介さない経路に分解します。これが可能となる理論的ポイントは以下のとおりです。

## 1. 経路分解の仮定と因果モデル

1.  **順序性（Temporal Ordering）** 介入 $X$→媒介変数 $M$→結果 $Y$ の順序が明確であり、時系列的に $X$ が先、 $M$ が中間、 $Y$ が最後に位置すること。
2.  **無交絡性（No Unmeasured Confounding）**
    -   $X$→$M$ の関係で交絡変数がない
    -   $M$→$Y$ の関係で交絡変数がない
    -   これらを満たすために、共変量 $\mathbf{C}$ を適切に制御する

この仮定下で、以下の２段階回帰モデルを推定します。

$$
\begin{aligned}
M &= \alpha + aX + \mathbf{C}\boldsymbol{\gamma} + \varepsilon_M,\\
Y &= \beta + c'X + bM + \mathbf{C}\boldsymbol{\delta} + \varepsilon_Y.
\end{aligned}
$$

-   1つ目の式で推定される係数 $a$ が「$X\to M$」の効果
-   2つ目の式で推定される係数 $b$ が「$M\to Y$（$X$制御下）」の効果
-   同時に推定される $c'$ が「$X\to Y$（媒介経路を除いた直接効果）」

## 2. 効果の分解

-   **間接効果（Indirect Effect）** = $a \times b$ $X$ がまず $M$ を変化させ、その変化が $Y$ に与える影響を表す。
-   **直接効果（Direct Effect）** = $c'$ $M$ を一定に固定した場合に、$X$ が $Y$ に与える影響。

これにより、**総効果（Total Effect）** $c = c' + a\times b$ が成り立ち、効果を経路ごとに定量化できます。

## 3. ブートストラップによる信頼区間

-   間接効果 $a\times b$ の標準誤差は複雑な組み合わせとなるため、**ブートストラップ**で標本を再抽出し間接効果の分布を推定します。
-   これにより、間接効果の信頼区間と有意性を評価可能となります。

## 4. 因果推論の枠組み

-   メディエーション分析は **潜在結果モデル（Potential Outcomes Framework）** に基づき、介入が媒介経路を通じても直接的にもアウトカムに与える効果を識別します。
-   適切な共変量調整と感度分析を実施することで、仮定違反の影響を評価し、因果解釈の信頼性を確保します。

------------------------------------------------------------------------

これらの原理により、政策介入がstuntingに影響を及ぼす複数の経路を切り分け、**媒介経路の強さ（間接効果）**と**介在しない影響（直接効果）**を定量的に評価できます。
