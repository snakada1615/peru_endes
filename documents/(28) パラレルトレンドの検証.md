# CRECER 平行トレンド検証のまとめ（stunting）

## 1. データとサーベイ設計

-   対象年次: 2007–2016 年（2011 年は v022 の欠損問題により除外）。
-   介入タイミング:
    -   treat1: 2009 年に CRECER 開始。
    -   treat2: 2011 年に CRECER 開始（データ上の最初のポスト期は 2012 年）。
-   サーベイ設計変数:
    -   PSU: v021（`psu_year = interaction(year, v021)` として年×PSU を使用）。
    -   Strata: v022（`strat_year = interaction(year, v022)` として年×strata を使用）。
    -   サンプルウェイト: v005 / 1e6。
-   本メモでは nt_ch_stunt\_\_Yes（子どもの stunting 指標）をアウトカムとして平行トレンドを検証。

## 2. 回帰ベースの pre-trend 検定（svyglm）

### 2.1 treat1 vs control（前処置期: 2007–2008）

推定式:

``` r
nt_ch_stunt__Yes ~ treat_d + year_c + treat_d:year_c
```

-   `treat_d`: treat1_grp = 1, control_grp = 0。
-   `year_c`: 2007 年を基準としたセンタリング（`year - 2007`）。

主な係数:

| 項目           | 推定値  | 標準誤差 | p値     |
|----------------|---------|----------|---------|
| treat_d        | 0.0962  | 0.0171   | \<0.001 |
| year_c         | -0.0351 | 0.0065   | \<0.001 |
| treat_d:year_c | 0.0276  | 0.0112   | 0.0136  |

**解釈**

-   `treat_d:year_c` は「前処置期における treat1 と control のトレンド（傾き）の差」を表します。
-   正で有意な係数（約 0.028、p ≈ 0.014）は、2007–2008 年において **treat1 地域の stunting が control 地域に比べて、より緩やかにしか減少していない（相対的には差が拡大している）** ことを示唆します。
-   したがって、treat1 については **平行トレンド仮定は満たされていない可能性が高い** と判断されます。

### 2.2 treat2 vs control（前処置期: 2007–2010）

同じ推定式:

``` r
nt_ch_stunt__Yes ~ treat_d + year_c + treat_d:year_c
```

-   `treat_d`: treat2_grp = 1, control_grp = 0。
-   `year_c`: 2007 年を基準としたセンタリング。

主な係数:

| 項目           | 推定値  | 標準誤差 | p値     |
|----------------|---------|----------|---------|
| treat_d        | 0.1644  | 0.0263   | \<0.001 |
| year_c         | -0.0240 | 0.0047   | \<0.001 |
| treat_d:year_c | -0.0148 | 0.0121   | 0.22    |

**解釈**

-   `treat_d:year_c` は負ですが、p 値 ≈ 0.22 と統計的には有意ではありません。
-   これは「treat2 と control の前処置期トレンドの傾きが異なる」という仮説を棄却できない、つまり **傾きの差の有力な証拠はない** ことを意味します。
-   一方で `treat_d` は正で有意であり、**レベルとしては常に treat2 の stunting の方が control より高い** ことは確認されます。
-   まとめると、treat2 については「レベル差はあるが、前処置期に明確な pre-trend の違いは観察されない」→ **平行トレンド仮定はおおむね妥当** と判断できます。

## 3. イベントスタディ図による確認

### 3.1 treat2 vs control（stunting）

![](イベントスタディ_treat1.png)

-   縦軸は、基準年（介入直前の年）に対する各年の差分の差（treat2 − control）の偏差を表し、95% 信頼区間を付したものです。
-   破線より左側（介入前）では、係数は一貫して **ゼロより上** に位置しており、treat2 地域の stunting が control 地域より高いことを示しています。ただし信頼区間は広く、ゼロも含んでおり、年次ごとのギャップの変化について強いトレンドは読み取りにくい状況です。
-   破線より右側（介入後）でも、すべての係数が **正** のままで、treat2 の stunting は引き続き control より高い状態が続いています。ギャップの大きさは年によって 0.08〜0.23 程度で上下するものの、明確な単調増加・単調減少のパターンは見られません。

**含意**

-   回帰ベースの検定結果と整合的に、イベントスタディ図からも **顕著な pre-trend（介入前のギャップの系統的な変化）は確認されない** 一方で、レベルとしては常に treat2 \> control であることが確認されます。
-   介入後もギャップは正のまま維持されますが、介入時点を境にギャップが急拡大／急縮小したという明瞭な変化は読み取れません。したがって、少なくとも stunting に関して **CRECER による大きな追加的効果を示す強い証拠は得られていない** と整理できます。

### 3.2 treat1 vs control（stunting）

![](イベントスタディ_treat2.png)

-   介入前（破線の左）では、多くの点が正の値を取り、treat1 地域の stunting が control 地域より高いことがわかります。
-   また、pre 期間内で係数の大きさがやや変動しており、`treat_d:year_c` が統計的に有意であった点とも整合的です。これは **介入前から treat1 と control の間でギャップの変化が生じていた可能性** を示唆します。
-   介入後（破線の右）の係数も概ね正ですが、pre との連続性が強く、介入を境にしたギャップの明瞭なレベル変化を特定するのは難しい印象です。

**含意**

-   treat1 については、svyglm の結果とイベントスタディ図の双方から **平行トレンド仮定の違反が疑われる** 状況です。
-   このため、treat1 に関する DID 推定結果は、主たる因果推定というよりは「補足的・記述的なエビデンス」と位置づけるのが安全と考えられます。

## 4. 今後の分析に向けた作業仮説

-   **treat2 vs control**
    -   前処置期の傾きの差は統計的に有意でなく、イベントスタディ図でも明瞭な pre-trend は確認されない。
    -   DID および mediator 分析の **主対象グループ** として用いることが妥当。
    -   ただし、効果の大きさは限定的で標準誤差も大きいため、推定結果の解釈には慎重さが必要。
-   **treat1 vs control**
    -   前処置期にトレンド差が有意であり、イベントスタディ図でも pre 期間のギャップ変化が示唆される。
    -   DID 推定は実施しつつも、主たる結論ではなく **ロバストネスチェック・参考資料** として扱う。
