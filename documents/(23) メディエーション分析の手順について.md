# メディエーション分析の進め方

-   **グルーピングの原則**
    -   コントロール群：非介入エリアの全期間 ＋ 介入エリアの「介入前」期間
    -   介入群：介入エリアの「介入後」期間のみ
-   **メディエーション分析とDIDの類似性**
    -   DIDと同様に「介入前＝コントロール」「介入後＝介入群」で処置変数を定義
    -   介入前データを含めることで共変量バランスや前提条件の検証が可能
-   **共変量の扱い**
    -   ダミー変数（0/1）と連続変数の混在は問題なし
    -   3値以上のカテゴリはone-hot化し、多重共線性を回避
-   **メディエーターの型別モデル指定**
    -   バイナリ（0/1）mediator：`glm(family = binomial)`
    -   連続 mediator：`glm(family = gaussian)` または `lm()`
    -   3レベル以上のカテゴリmediator：
        -   2値に再分類 または
        -   多項ロジスティック＆別手法（g-computation等）を検討
-   **処理変数（treatment_var）の設定**
    -   0 = コントロール期間または非介入エリア
    -   1 = 介入後の介入エリア
-   **モデル構築時の注意**
    -   年次トレンド調整に `+ as.factor(year)` を追加
    -   欠損値除外後のサンプルサイズを確認
    -   モデル収束と係数のNAチェックを行い、問題があれば該当mediatorをスキップ
-   **実装サンプル**

``` r
fam_M <- if (all(df[[mediator]] %in% c(0,1))) binomial else gaussian
model_M <- glm(formula_M, data = df, family = fam_M)
model_Y <- glm(formula_Y, data = df, family = binomial)
med_out <- mediation::mediate(model_M, model_Y, treat="treatment", mediator=mediator, control.value=0, treat.value=1)
```
