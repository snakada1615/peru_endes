# 質問

```         
LASSOで共変量の絞り込みを進めています。共変量に、ダミー変数、連続変数（実数）、カテゴリ変数の３種類が含まれていますが、カテゴリ変数については全てダミーに変換してからLASSOに用いるマトリックスを作成すべきでしょうか
```

# 回答

LASSOでカテゴリ変数を扱う場合は、必ずダミー変数（ワンホット）に変換してから解析用マトリックスを作成してください。以下の点に注意するとよいでしょう。

**1. モデル行列の作成** –
Rの`glmnet`パッケージでは、モデル式とデータフレームを渡す際に内部で自動的にダミー変換を行ってくれます。

``` r
library(glmnet)
x <- model.matrix(~ . - 1, data = df)   # df中の因子型変数が自動的にダミー化される
fit <- glmnet(x, y, alpha = 1)
```

このように`model.matrix(~ . - 1, …)`を使うと、カテゴリ変数はすべて水準ごとの0/1ダミーに展開され、切片も含めない形（`- 1`）で行列が作れます。

**2. ダミー変数作成のポイント**

-   **基準レベルの省略**
    水準数が$k$のカテゴリ変数は、$(k-1)$個のダミー変数にします（多重共線性回避）。`model.matrix`では自動的にリファレンスレベルが1つ省かれます。
-   **順序（Ordinal）変数**
    順序をもつカテゴリ変数はダミー化せずに整数値（1,2,3…）のまま扱う方法もありますが、LASSOでは「真に連続」とみなされないため、やはりダミー化してモデル式で順序を考慮するか、後述の**スプライン**や**連続化**アプローチを検討します。

**3. 変数の標準化**
LASSOでは正則化項に係数の大きさが直接関わるため、すべての変数（ダミーも含む）は同じスケールであることが望ましいです。`glmnet`ではデフォルトで標準化（`standardize = TRUE`）が行われますが、独自にダミーを作る場合も、連続変数は平均0・分散1にスケーリングしておくと解釈性と収束性が向上します。

**4. グループLASSOの検討**
カテゴリ変数の水準ごとに分割されたダミー変数は、単独LASSOだと水準ごとにバラバラに選択／削除されてしまい、意味のある「全部入り」「全部抜き」の判断ができません。

-   水準をまとめて選択したい場合は、**グループLASSO**（`grpreg`パッケージなど）を使い、各カテゴリのダミー群を1つのグループとして設定すると便利です。

------------------------------------------------------------------------

**まとめ**
カテゴリ変数は必ず（基準レベルを除く）ワンホットダミーに展開してからLASSO用マトリックスを作成し、連続変数と同様に正規化を行いましょう。単一LASSOでは水準ごとに個別選択される点に留意し、必要に応じてグループLASSOを検討するとより整合性のあるモデル構築が可能です。

------------------------------------------------------------------------

# 追加質問

```         
カテゴリ変数はglmetを適用することで自動的にダミー変数に変換されるので、手作業でダミー変数かするのではなく、glmet関数に任せれば良いという理解で正しいでしょうか
```

はい、その理解で問題ありません。厳密には、**glmnet**自体は因子（factor）を直接扱えないため、モデル行列（design
matrix）を渡す必要があります。しかし、R標準の **model.matrix()**
を使すれば、因子のワンホットダミー化や基準レベルの省略などを自動で行ってくれるので、手作業でダミーを作る必要はありません。

具体的には以下のようにします：

``` r
library(glmnet)

# df: データフレーム（因子型のカテゴリ変数を含む）
# response: 応答変数ベクトル
x <- model.matrix(~ . - 1, data = df)  # 因子を自動でダミー化、切片は含まれない
fit <- glmnet(x, response, alpha = 1)
```

– `model.matrix(~ . - 1, …)` で説明変数すべてを変換 – 因子は自動的に
(k−1) 個のダミーに展開 – `glmnet()` にはダミー化済みの数値行列を渡すだけ

この方法なら、ダミー化の詳細を手作業で管理せずに済み、Rの仕様どおりに自動処理してくれます。
